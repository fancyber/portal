# Fancyber

Enterprise AI engineering platform website for Fancyber.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to GitHub Pages

1. Create a GitHub repository.
2. Push this project to the repository.
3. Run:

```bash
npm run deploy
```

4. In GitHub:
   - Open repository Settings
   - Open Pages
   - Set source to `gh-pages` branch

The site will deploy automatically from the generated `gh-pages` branch.
